## Summary
With this scenario, I wanted to ensure that secure measures were put into place for administrators, users, and contractors for access to Azure, if those measures would automatically be in place or not, and establish a secure baseline that could ease the onboarding process when new members of the organization are added.

## The Problem
Shirabuki Corporation wants to create a secure baseline for their Azure identity and access management systems. The company wants to make sure that there are secure measures in place for users in the event of new user onboarding, and whether the security measures are in place by default or toggled manually.

## What Was Built
- This scenario is designed to check for the following:
   - New user onboarding security measures
   - Secure baselines
   - Default security measures
