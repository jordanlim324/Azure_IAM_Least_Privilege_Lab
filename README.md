# Azure_IAM_Least_Privilege_Lab

Demonstrating least-privilege IAM design in Microsoft Azure's EntraID using free-tier RBAC and Security Defaults.

## Project Overview
This project is designed to leverage free Azure resources to understand and practice IAM principles for a fictionalized organization (Shirabuki Corp). The primary goal of this project is to build a practical, demonstrable experience  with enterprise access control patterns before applying them in a production environment. With Shirabuki Corp., there are two admins, three employees, and one contractor.

## Skills Demonstrated
- Least privilege access design
- Custom RBAC roles
- Group-based access assignment
- Security baseline configurations
